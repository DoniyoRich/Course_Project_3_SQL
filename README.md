## Курсовой проект №3. "Парсинг вакансий с сайта HeadHunter и работа с PostgreSQL."

## Цель проекта
- Разработать программу, которая будет получать вакансии по выбранным работодателям и записывать информацию в базу данных ***PostgreSQL***.
- Закрепить знания из пройденного модуля по базам данных.

## Описание

Курсовой проект представляет собой готовое приложение для работы с вакансиями с сайта hh.ru.
В проекте реализованы следующие классы и модули:

- класс ***DBManager***. Реализует методы создания базы данных, создания таблиц, внесения новых записей, различные виды выборок из базы данных.
- класс ***EmployerVacancy***. Данный класс реализует непосредственный GET запрос на API сайта hh.ru, получает данные по вакансиям по номеру id Работодателя.
- класс ***FileSaverABS***. Абстрактный класс для класса ***ExcelSaver***.
- класс ***ExcelSaver***. Класс реализует метод сохранения выборки из базы данных в файл формата .xlsx (Excel).
- модуль ***main***. Основной модуль программы, операции взаимодействия с Пользователем.
- модуль ***constants***. В модуле собраны константы, используемые в различных точках программы.
- модуль ***utils***. Модуль содержит небольшие вспомогательные утилиты, такие как отображение пользовательского меню, получение ответ от Пользователя
на различные запросы программы, операции валидации зарплаты и другие.

Точка входа в программу - модуль ***main***.
